# Página da disciplina GCC1734

Esta pasta contém a página estática da disciplina **GCC1734 — Inteligência Artificial**, pronta para publicação pelo GitHub Pages.

## Arquivos

```text
docs/
├── index.html
├── styles.css
└── README.md
```

A página usa apenas HTML5 e CSS próprio. Não há framework, JavaScript ou dependência externa obrigatória.

## Publicação pelo GitHub Pages

1. Abra o repositório `https://github.com/AILAB-CEFET-RJ/gcc1734`.
2. Acesse **Settings**.
3. No menu lateral, acesse **Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**.
6. Selecione a pasta **/docs**.
7. Clique em **Save**.

Endereço esperado:

`https://ailab-cefet-rj.github.io/gcc1734/`

A primeira publicação pode levar alguns minutos.

## Atualização

Edite `docs/index.html` para alterar conteúdo e `docs/styles.css` para alterar a apresentação. Depois, faça commit e push para a branch `main`.

Os links das notas apontam para arquivos confirmados no repositório:

- `notas_aula/GCC1734-admin.pdf`
- `notas_aula/GCC1734-nota01.pdf` até `GCC1734-nota08.pdf`
